Başlangıç rehberi

Ekibiniz için özel çalışma alanı.

theta-workplace, verileri kendi sunucunuzda tutarak ekiplerin local ağda veya Tailscale ile uzaktan iletişim kurmasını sağlar.

01

Ne işe yarar?

Kurum içi ekipler için oda tabanlı mesajlaşma sunar. Odalar oluşturabilir, parola koyabilir, oda sahibinin onay sistemiyle Tailscale üzerinden gelen kişileri kabul veya reddedebilirsiniz.

02

Local ağda kullanma

Sunucunun çalıştığı bilgisayar ile telefon veya diğer cihazlar aynı Wi-Fi ağında olmalı. Sunucuyu başlatın ve bilgisayarın Wi-Fi IP adresini port 3000 ile açın.

npm start
http://BILGISAYAR-IP:3000
03

Tailscale ile uzaktan kullanma

Sunucuda Tailscale'e giriş yapın. Telefon ve izin verdiğiniz kişiler de aynı tailnet'e bağlansın. Tailscale Serve ile HTTPS adresi oluşturun. Odaya giriş için ayrıca oda sahibinin onayı gerekir.

npm run start:tailscale
tailscale serve --bg http://127.0.0.1:3000
04

Sunucu kurulumu

Uygulamayı Windows, Ubuntu, WSL veya bir VPS üzerinde çalıştırabilirsiniz. Node.js 18 veya üzeri yeterlidir. Windows için PowerShell, Ubuntu için shell kurulum scripti vardır.

npm install
npm start

Hızlı başlangıç

Üç adımda çalıştırın.

  1. Node.js 18+ kurun ve proje klasörünü açın.
  2. npm install ardından npm start komutunu çalıştırın.
  3. Local için localhost:3000, uzaktan kullanım için Tailscale HTTPS adresini açın.
